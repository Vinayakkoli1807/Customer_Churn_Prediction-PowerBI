# Customer Churn Analysis Dashboard

## Project Overview

This project analyzes customer churn behavior using Power BI. The objective is to identify factors contributing to customer attrition and provide actionable insights for improving customer retention.

## Tools Used

- Power BI
- Power Query
- DAX
- Excel

## Data Preparation

- Appended multiple customer datasets
- Cleaned and transformed data using Power Query
- Verified data types and handled inconsistencies

## KPIs

- Total Customers
- Churned Customers
- Active Customers
- Churn Rate %
- Revenue Lost

## Dashboard Features

### Executive Overview
- Customer KPIs
- Churn Distribution
- State-wise Churn Analysis

### Customer Behavior Analysis
- Service Calls vs Churn
- Account Length Analysis
- International Plan Impact
- Voice Mail Plan Impact

### Usage Pattern Analysis
- Day Usage Analysis
- Evening Usage Analysis
- Night Usage Analysis
- International Usage Analysis

### Revenue Impact Analysis
- Revenue by Churn Status
- Revenue Lost Due to Churn

## Key Insights

- Customers with higher customer service interactions showed increased churn risk.
- International plan users exhibited higher churn tendencies.
- Certain regions contributed disproportionately to overall churn.
- Churned customers represented significant revenue loss.
